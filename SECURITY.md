# Security policy

This tap only points Homebrew at YapYap's releases, so security reports about
the casks or YapYap itself go to YapYap.

**Do not open a public issue.** Report vulnerabilities through GitHub's
[private vulnerability reporting for YapYap](https://github.com/vascoguita/yapyap/security/advisories/new),
as YapYap's [security policy](https://github.com/vascoguita/yapyap/blob/master/SECURITY.md)
describes. Only the latest release and beta receive fixes, and the casks
follow them.
